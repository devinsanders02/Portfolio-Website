# Homepage contour lines

`assets/topo/terrain.svg` is generated by `build.mjs`. Right now it uses a
**procedural stand-in** (a made-up massif with ridges, valleys and a cirque).
The goal is to swap it for real **Mount Bierstadt** elevation data.

## Change the look (no rebuild needed)

All colours, line weights, opacity and the fade are CSS variables at the top of
`css/site.css` under **TOPOGRAPHIC BACKGROUND CONTROLS** (`--topo-low`,
`--topo-mid`, `--topo-high`, `--topo-width`, `--topo-index-weight`,
`--topo-opacity`, `--topo-fade-*`, `--topo-draw`).

## Change the shape (rebuild)

Edit `config.json`, then:

```
cd tools/terrain
npm install        # first time only
node build.mjs
```

- `placement.peakX / peakY` — where the summit sits (0–1 of the screen)
- `placement.scale` — zoom in/out on the terrain
- `placement.rotateDeg` — turn the mountain
- `contours.count` (procedural) or `dem.intervalMeters` (real data) — line density
- `contours.indexEvery` — every Nth line is a heavier "index" line

## Getting the Mount Bierstadt data (OpenTopography)

The build server can't reach OpenTopography, so this part is on you. About 5 minutes.

1. **Make a free account** at https://opentopography.org (top right, "My Account" → register).
2. **Get an API key**: log in, open your MyOpenTopo dashboard and click
   **"Get an API Key"** (or "Request an API key" on the home page).
3. **Download the data** by pasting this into your browser, with your key at the end:

   ```
   https://portal.opentopography.org/API/usgsdem?datasetName=USGS10m&south=39.555&north=39.610&west=-105.715&east=-105.625&outputFormat=GTiff&API_Key=YOUR_KEY
   ```

   - Dataset: **USGS 3DEP 1/3 arc-second (~10 m)** (`USGS10m`), the best free resolution for the US
   - Area: a box around Bierstadt, including the Sawtooth ridge toward Mount Evans/Blue Sky
   - Format: **GeoTIFF** (`GTiff`)

   It downloads a `.tif` file of a few MB.
4. **Send the .tif to Claude** (or put it at `tools/terrain/data/bierstadt.tif`).
   Then in `config.json` set `"source": "dem"` and run `node build.mjs`.

The summit label (`dem.summitLabel`) fills its elevation in from the data
itself, so the number on the page always matches the file.

If the API link gives an error, use the website instead: **Data → Find Data Map**,
search "Mount Bierstadt", choose **USGS 3DEP 1/3 arc-second DEM**, draw a box
around the peak, pick **GeoTIFF**, submit, and download from the job page.
